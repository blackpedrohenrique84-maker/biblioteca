# opções de classe
```bash
- opção C - Livro de Biblioteca

  atributos: títulos, Autor, disponível(True/False)
  métodos: emprestar() - só se disponível; muda para False
           devolver() - só se emprestado; muda para True
           ficha() - mostra o título, autor e status


  atividade prática

  crie uma classe com pelo menos 3 atributos, inicializando por meio de construtor __init__, e implemente no mínimo 2 métodos que representem comportamentos do objeto, utilizando corretamente o self. Em seguida, crie 2 instâncias da classe com valores diferentes, execute seus métodos e apresente os resultados no terminal. Pelo menos um método deverá ser utilizado na estrutura condicional (if/else) para realizar uma validação ou tomada de decisão.
  
```
